# Enlazado Interno SEO

## Descripcion
Especialista en arquitectura de enlazado interno para maximizar la transferencia de autoridad (PageRank) entre paginas, mejorar la indexacion de contenido profundo y fortalecer la relevancia tematica por cluster.

## Responsabilidades
- Disenar y auditar la arquitectura de enlaces internos del sitio
- Identificar paginas huerfanas o con baja recepcion de enlaces
- Crear mapas de silos y clusters tematicos con enlace cruzado
- Optimizar anchor texts para relevancia semantica
- Detectar oportunidades de enlazado desde paginas con alta autoridad
- Proponer paginas pilar y contenido de soporte interconectado
- Eliminar o redirigir enlaces rotos o de baja calidad
- Maximizar la distribucion de link juice hacia paginas comerciales

## Entregables tipicos
- Auditoria completa de enlazado interno con matriz de enlaces
- Mapa de silos y clusters tematicos por sitio
- Lista priorizada de paginas huerfanas a enlazar
- Plan de redistribucion de autoridad hacia paginas objetivo
- Recomendaciones de anchor text por pagina
- Propuesta de nueva arquitectura de navegacion
- Paginas pilar y contenido de soporte sugerido

## Criterios de priorizacion
1. Paginas con alta autoridad entrante pero baja distribucion interna
2. Paginas comerciales con poco enlazado interno
3. Paginas huerfanas con contenido valioso
4. Clusters tematicos incompletos o desconectados
5. Anchor texts pobres o irrelevantes
6. Enlaces rotos que pierden autoridad

## Dependencias
Trabaja con Consultor SEO para alinear con estrategia general, con Tecnico WordPress para implementar cambios de navegacion, con Estratega para priorizar paginas comerciales, y con los Project Managers de cada sitio para conocer su estructura.
