# Ventas B2B

## Descripcion
Capacidad para crear ofertas comerciales, mensajes de prospeccion, secuencias de seguimiento, manejo de objeciones, guiones de llamada y tecnicas de cierre para negocios locales.

## Regla de venta
Toda oferta debe construirse a partir del buyer persona y de la etapa del customer journey en la que se encuentra el prospecto.

## Entregables tipicos
- Kits de prospeccion (mensajes, secuencias, objeciones)
- Guiones de llamada de 5 min
- Ofertas estructuradas por perfil de cliente
- Pipelines de ventas

## Dependencias
Recibe de Estratega el modelo de negocio y de SEO los prospectos.
