# Consultoria SEO y Monetizacion

## Descripcion
Capacidad para detectar oportunidades de ingresos por sitio analizando datos de Search Console, identificando keywords con intencion comercial, auditando paginas y proponiendo estrategias de monetizacion B2B.

## Regla de analisis
Antes de proponer monetizacion, definir buyer persona y etapa del customer journey (descubrimiento, consideracion, decision, retencion o recomendacion).

## Entregables tipicos
- Listas priorizadas de prospectos con datos de trafico
- Auditorias SEO con oportunidades comerciales
- Identificacion de keywords con intencion de compra
- Analisis de brechas de contenido
- Enlazado interno y arquitectura de informacion
- Hipotesis de buyer persona y etapa del journey para cada oportunidad

## Dependencias
Trabaja con Estratega para priorizar y con Ventas para accionar.
