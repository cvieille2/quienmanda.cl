# Gestion de Proyectos Web

## Descripcion
Capacidad para gestionar sitios web de nicho: seguimiento de metricas, coordinacion de tareas, reporte al Director, identificacion de oportunidades comerciales por sitio.

## Entregables tipicos
- Reportes semanales de estado por sitio
- Listas de prospectos comerciales
- Planes de contenido editorial
- Seguimiento de KPIs (trafico, fichas, ingresos)

## Dependencias
Recibe insumos de SEO, Ventas, Tecnico y CRO.
