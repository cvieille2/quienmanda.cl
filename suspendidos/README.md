## Reactivación

Para reactivar un agente:
1. Mover su directorio de vuelta a `agentes/`
2. Actualizar `lanzar-equipo.ps1` para incluirlo
3. Registrar en memoria el motivo de reactivación

Los directorios originales se mantienen intactos en `suspendidos/agentes/`.
