## Regla de uso
- Si una URL alta no tiene keyword clara, el problema es de arquitectura o contenido.
- Si una keyword aparece en varias URLs, marcar canibalizacion de inmediato.
- Si una URL está en baja prioridad, no merece optimizacion cosmética antes de limpieza o fusión.
