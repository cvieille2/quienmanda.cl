## Conversion en fichas individuales de motel

### CTAs obligatorios (todos above the fold)
| CTA | Ubicacion | Prioridad |
|---|---|---|
| "Ver tarifas" | Hero (boton primario) | Critico |
| "Llamar" | Hero (boton secundario) | Alto |
| "WhatsApp" | Hero (boton secundario) | Alto |
| "Como llegar" | Hero + seccion mapa | Medio |

### Reglas de conversion
1. **NO** poner anuncios AdSense cerca del CTA principal ni del boton "Llamar"
2. **NO** poner nada entre el hero y la galeria que distraiga del CTA
3. La fecha de verificacion debe ser visible (genera confianza)
4. Las resenas deben ser propias del directorio, no importadas
5. El formulario de contacto: solo nombre + WhatsApp

### Layout recomendado por seccion
| Seccion | Elementos de conversion |
|---|---|
| Hero | Breadcrumbs + H1 + resumen + badges + 4 CTAs + fecha verificacion |
| Galeria | Imagenes reales, hero no lazy |
| Descripcion | Texto editorial unico, sin plantillas |
| Servicios | Iconos + lista clara |
| Tarifas | Tabla scaneable, CTA "Llamar para reservar" |
| Mapa | Embed lazy, direccion visible |
| Resenas | Estrellas + texto verificable |
| FAQ | Acordeon, respuestas cortas |
| Relacionados | Enlaces a otras fichas en misma ciudad |

### Pruebas A/B sugeridas (nuevas)
1. Hero con video vs hero con imagen
2. CTAS "Ver tarifas" vs "Ver precios" vs "Reservar ahora"
3. Precio desde en badge vs sin badge
4. Resenas visibles vs resenas plegadas
5. Con fecha de verificacion vs sin fecha
