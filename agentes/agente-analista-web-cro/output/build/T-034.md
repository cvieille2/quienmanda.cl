# Build CRO - Recomendaciones de Retencion por URL
## Sesion: 2026-05-21

## Resumen
Recomendaciones para mejorar lectura, claridad y permanencia en el cluster Piqueros.

---

### Recomendaciones generales para el cluster
1. **Parrafos cortos**: Maximo 3-4 lineas por parrafo para facilitar escaneo
2. **Subtitulos descriptivos**: Cada H2 debe responder una pregunta o prometer un beneficio
3. **Tablas comparativas**: Para diferencias entre especies (tamano, color, habitat, distribucion)
4. **Imagenes en contexto**: Cada foto de ave debe incluir pie de foto con nombre cientifico y caracteristica clave
5. **FAQ al final**: Responder preguntas reales de la SERP en formato pregunta-respuesta
6. **Tiempo de lectura**: Incluir estimacion ("Lectura: 5 minutos") para gestionar expectativas
7. **Enlaces internos relevantes**: No mas de 3 por parrafo, contextuales
