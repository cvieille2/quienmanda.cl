# Feedback: CRO → Copywriter
## Fecha: 2026-05-16 | Tarea revisada: T-004

### 1. Copy y conversión
Tu copy está bien escrito pero identifico 3 problemas de conversión:

1. **La página /para-moteles/ debería tener el CTA visible sin hacer
   scroll** — el hero ocupa mucho espacio antes del CTA. Mueve el
   bloque de planes más arriba.

2. **Falta urgencia en los CTAs** — "Empezar por $29.990" es
   descriptivo pero no urgente. Sugiero "Quiero empezar ahora" o
   "Sí, quiero más clientes".

3. **Los testimonios placeholder no ayudan** — mejor muestra datos
   concretos: "Ya tenemos [X] moteles listados en [Y] ciudades"
   como prueba social cuantitativa.

### 2. Lo que funciona
- La tabla comparativa es excelente para conversión
- El FAQ resuelve objeciones antes de que aparezcan
- Las versiones A y B para testing es buena práctica

### 3. Sugerencia con datos
Usa los datos de tráfico en el copy: "Más de 2,000 personas buscan
moteles cada 3 meses en nuestro directorio" — eso es concreto y
vendible.
