# Mensajes Operativos - T-025 y T-026
## Sesion: 2026-05-17

## Instruccion general
No quiero analisis adicionales. Quiero entregables listos para publicar o implementar. Cada respuesta debe traer URL afectada, cambio exacto y criterio de cierre.

---

## Mensajes para T-026 - Portada

### Estratega
Definime el mensaje comercial unico de la portada de `infomoteles.cl`. Quiero una sola promesa principal, una accion prioritaria y una recomendacion clara de hacia donde debe empujar la home. Entrega lista para que copy, diseno y CRO trabajen encima. No quiero alternativas infinitas.

### Consultor SEO Monetizacion
Revisá la portada como pagina de entrada comercial. Necesito title, meta description, H1 y subtitulo alineados con la intencion real de busqueda. Entrega una propuesta concreta con keyword principal, secundarias y razon de cambio. No quiero diagnostico general.

### Copywriter de Conversion
Redacta el hero y el texto principal de la portada para que se entienda en 5 segundos que ofrece el sitio y cual es el siguiente paso. Entregame titular, subtitular, CTA principal y CTA secundario. Quiero una version lista para publicar.

### Disenador UI Web
Diseña el primer pantallazo de la home para convertir mejor en mobile y desktop. El CTA principal debe quedar visible sin scroll y la jerarquia visual debe empujar a la ruta comercial. Entrega layout claro y aplicable.

### Analista Web CRO
Diagnostica por que la portada no convierte y definime 3 cambios rapidos y 3 de alto impacto. Quiero friccion, puntos de fuga y metricas a medir despues de publicar. No quiero seguir analizando lo mismo sin accion.

### Tecnico WordPress / Automatizacion
Implementa y valida los cambios tecnicos de la portada. Necesito version publicada o lista para publicar, validacion mobile, revision de tracking y evidencia de que no rompiste navegacion ni analytics. No acepto solo planes.

### Enlazado Interno
Conecta la home con las URLs monetizables correctas. Quiero mapa de enlaces internos, anchors sugeridos y prioridad de destinos. La portada debe empujar autoridad a fichas y a `para-moteles`.

### PM Infomoteles
Coordiná la publicacion y el reporte comparativo de la nueva portada. Necesito estado antes/despues, checklist final y siguiente accion si mejora o no mejora. Quiero trazabilidad, no solo confirmacion verbal.

## Mensajes para T-025 - Fichas con trafico

### SEO Monetizacion
Audita las 3 fichas foco con mayor traccion: `/motel-diamante-curico/`, `/antofagasta/motel-serrano-antofagasta/` y `/calama/motel-euro-calama/`. Quiero consultas, CTR, posicion, impresiones y oportunidad real por URL. Entrega criterio de prioridad y keywords para reescritura.

### Copywriter de Conversion
Reescribe title, meta description, H1 y subtitulo de las 3 fichas foco para subir CTR sin perder relevancia local. Necesito copy listo para publicar por cada URL y un criterio claro de cierre.

### Disenador UI Web
Redisená el hero de las fichas foco para que precio, ubicacion, prueba social y CTA queden arriba del primer scroll. Entrega mobile-first y con jerarquia visual pensada para conversion.

### Analista Web CRO
Revisá la conversion de las fichas foco y detectá friccion, formularios, CTAs y fuga de atencion. Quiero 3 cambios rapidos y 3 de alto impacto por ficha, con metricas para validar.

### Tecnico WordPress / Automatizacion
Validá tracking, mobile, velocidad y posibles redirecciones de las fichas foco. Necesito checklist tecnico por URL y evidencia de que cada ficha queda medible y estable.

### Enlazado Interno
Reforzá el enlazado interno hacia las fichas foco desde hubs y URLs con trafico real. Entregame mapa de enlaces, anchors y prioridad de paginas origen.

### Estratega
Definí el orden del siguiente lote de fichas despues de esta primera ola. Quiero secuencia por potencial comercial, no por intuicion.

### PM Infomoteles
Coordiná publicacion, revision y reporte de la primera ola de fichas foco. Necesito confirmacion de cambio publicado, checklist final y comparacion antes/despues.
