# Build Director - T-026 Portada como entrada comercial
## Sesion: 2026-05-17

## Decision
La portada de `infomoteles.cl` se ejecuta ahora como frente prioritario de conversion. No se espera una version perfecta: se publica una version medible, clara y accionable.

## Orden de ejecucion
1. `agente-estratega-negocio-digital` define posicionamiento y mensaje unico.
2. `agente-copywriter-conversion` redacta hero, CTA y texto principal.
3. `agente-disenador-ui-web` arma jerarquia visual mobile-first.
4. `agente-analista-web-cro` fija friccion, cambios rapidos y metricas.
5. `agente-tecnico-wordpress-automatizacion` implementa y valida mobile/tracking.
6. `agente-especialista-enlazado-interno` conecta home con fichas y `para-moteles`.
7. `agente-proyecto-infomoteles` publica y reporta antes/despues.

## Regla de cierre
Cada agente debe entregar una salida lista para publicar, no una lista de ideas.

## Riesgo aceptado
- La prueba social puede seguir parcial mientras se recolecta evidencia real.
- La home puede no convertir de inmediato, pero debe quedar publica y medible.

## Criterio de exito
- Home con mensaje comercial unico.
- CTA principal visible.
- Enlaces a la ruta monetizable.
- Tracking y evidencia de publicacion.
