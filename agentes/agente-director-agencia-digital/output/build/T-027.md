# Build Director - T-027 Arquitectura limpia para 10k/dia
## Sesion: 2026-05-17

## Decision
Se ejecuta una limpieza de arquitectura para quitar duplicados, ordenar intenciones y dejar el sitio listo para crecer sin canibalizarse.

## Orden de ejecucion
1. Home fuerte.
2. Landings por ciudad/zona.
3. Fichas de motel bien resueltas.
4. Fusion de posts viejos utiles.

## Regla de cierre
Cada frente debe entregar una URL, una intencion y un criterio de cierre.

## Riesgo aceptado
- Se van a consolidar o retirar URLs que hoy no aportan.
- Algunas piezas antiguas dejaran de existir como paginas sueltas si conviene fusionarlas.

## Criterio de exito
- Menos duplicados.
- Menos canibalizacion.
- Mejor distribucion de autoridad.
- Mejor camino hacia conversion.
