# Lanzamiento Operativo - T-032 aves de Rapa Nui
## Sesion: 2026-05-21

## Contexto
Se activa un cluster sobre aves de Rapa Nui para `avesnativaschilenas.cl`. La referencia top ya existe en Google, asi que el trabajo no es improvisar: es separar intenciones, publicar URLs utiles y dejar el tema bien conectado.

## Orden de arranque
1. SEO: definir intenciones y mapa final de URLs.
2. Copywriter: entregar copy final por URL.
3. Tecnico: publicar hub y paginas satelite.
4. Enlazado Interno: conectar toda la arquitectura.
5. PM Aves: revisar, consolidar y cerrar.

## Reglas de operacion
- Ningun agente debe devolver solo analisis.
- Cada pagina debe cubrir una intencion distinta.
- Si una URL duplica otra, se consolida antes de publicar.
- No usar datos dudosos sobre especies o nombres locales.

## Resultado esperado
- Un hub sobre aves de Rapa Nui.
- Un conjunto de paginas satelite por intencion.
- Enlazado interno claro y medible.
- Base lista para Search Console y futuras mejoras.

## Criterio de cierre de T-032
Hub publicado + minimo 6 paginas satelite publicadas o consolidadas + una URL por intencion + cluster enlazado + informacion consistente con la referencia.
