# Mensajes Operativos - T-034 Piqueros por Post
## Sesion: 2026-05-21

## Instruccion general
Cada post del cluster `Piqueros` va a tener su propia tarea. No quiero analisis globales sueltos: quiero una ficha por URL con keyword principal, top 3 real de Google, competencia, estructura, resumen, imagenes, tablas, FAQs y gap analysis.

---

### SEO Monetizacion
Para cada una de estas URLs, busca la keyword principal en Google y documenta el top 3 real: `/piqueros/piquero-blanco/`, `/piqueros/piquero-cafe/`, `/piqueros/piquero-de-patas-coloradas/` y `/piqueros/piquero-peruano/`. Entregame URLs competidoras, keywords principales posicionadas por cada competidor, intencion dominante, schema probable, longitud aproximada, enlaces internos visibles, titles, estructura H1-H3, resumen, imagenes, tablas, FAQs y la brecha exacta frente a nuestra pagina.

### Copywriter de Conversion
Con la SERP real, define que title, H1, subtitulos, apertura, FAQs y bloques faltan en cada ficha. No copies al competidor: conviertelo en una version superior, mas clara y mejor orientada a la intencion de busqueda.

### Disenador UI Web
Analiza que recursos visuales usan los tres primeros resultados: imagen unica, galeria, tablas, cards, comparativas o bloques destacados. Define que formato visual necesita cada post para competir mejor y que schema o bloques faltan para igualar o superar al lider.

### Tecnico WordPress / Automatizacion
Deja listo el soporte tecnico para aplicar los cambios ganadores por URL: destacadas unicas, orden de bloques, tablas, FAQs, anclas y rendimiento mobile. Si una ficha necesita ajuste tecnico extra, dejalo explicitado.

### Enlazado Interno
Propone la malla de enlaces del cluster `Piqueros` para que el hub y cada ficha empujen autoridad hacia la mejor URL. No dejes ninguna pagina aislada.

### Analista Web CRO
Marca que elementos de la competencia mejoran lectura, claridad y permanencia. Ajusta las recomendaciones para retener mejor y empujar al siguiente clic.

### Estratega
Consolida un plan de upgrade por URL con prioridad, esfuerzo e impacto esperado. Si hace falta usar todo el equipo, usalo. El objetivo es la primera posicion.

### PM Aves
Coordina la ejecucion y cierra con una tabla por URL: keyword principal, top 3, brecha principal, cambio prioritario y responsable.

---

## Resultado esperado
- Cuatro fichas auditadas.
- Competencia documentada por URL.
- Brechas claras por contenido y formato.
- Plan de mejora listo para ejecutar.
