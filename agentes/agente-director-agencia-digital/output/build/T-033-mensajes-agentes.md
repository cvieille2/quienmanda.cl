# Mensajes Operativos - T-033 Piqueros SERP
## Sesion: 2026-05-21

## Instruccion general
Quiero un analisis por URL, no un informe global. Para cada post del cluster piqueros hay que buscar la keyword principal en Google, tomar el top 3 real y comparar con nuestra pagina. Si hace falta, usa SEO, copy, CRO, diseno, tecnico y enlazado interno para construir una pagina mejor que la competencia.

---

### SEO Monetizacion
Para cada una de estas URLs: `/piqueros/piquero-blanco/`, `/piqueros/piquero-cafe/`, `/piqueros/piquero-de-patas-coloradas/` y `/piqueros/piquero-peruano/`, busca primero su keyword principal en Google y documenta el top 3 real. Entregame por cada una: URL competidora, titulo, estructura H1-H3, resumen de contenido, imagen principal, imagenes internas, tablas, FAQs, schema probable y el angulo de contenido que esta ganando la SERP.

### Copywriter de Conversion
Con el analisis SERP en mano, define que nos falta en cada ficha para superarla: title, H1, subtitulos, apertura, bloques de valor, FAQ, CTAs internos y explicaciones que falten. No copies al competidor; traduce el formato ganador en una version mejor, mas clara y mas completa.

### Disenador UI Web
Revisa que tipo de recursos visuales usan los top 3: foto unica, galeria, cards, tablas, ilustraciones, comparativas o bloques destacados. Define que componente visual necesita cada ficha para competir mejor sin romper el estilo del sitio.

### Tecnico WordPress / Automatizacion
Deja lista la estructura para aplicar los cambios ganadores: imagen destacada unica por post, orden de bloques, anclas, tabla si hace falta, FAQs y cualquier ajuste tecnico necesario para rendimiento y mobile. Si una URL requiere soporte tecnico extra, explicalo con precision.

### Enlazado Interno
Propone la malla de enlaces del cluster piqueros: hub, fichas hermanas y enlaces cruzados donde tenga sentido. El objetivo es que cada URL reciba autoridad y que el cluster completo empuje a la mejor ficha.

### Analista Web CRO
Marca que partes de la SERP o de los competidores mejoran la experiencia: lectura rapida, claridad, profundidad, visuales, comparativas, preguntas frecuentes o bloques de identificacion. Ajusta las recomendaciones para que cada post retenga mejor y convierta en lectura de siguiente paso.

### Estratega
Consolida el plan final para llevar cada post a primera posicion. Necesito una prioridad por URL, esfuerzo estimado, impacto esperado y orden de ejecucion. Si para ganar hay que usar todo el equipo, dilo sin dudar.

### PM Aves
Coordina el flujo completo y exige entrega por URL. Cierra con una tabla de: keyword principal, top 3, brecha principal, cambio prioritario y responsable.

- Brechas claras por contenido y formato.
