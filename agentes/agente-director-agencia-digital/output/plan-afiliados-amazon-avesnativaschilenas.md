# Plan de Afiliados Amazon.es — avesnativaschilenas.cl
## Basado en Search Console 2026-05-21

## Estado actual
El sitio YA tiene enlaces de afiliado Amazon (amzn.to) en:
- /jaulas/ — jaulas, accesorios para jaulas
- /nidos/ — nidos, comederos
- /tienda/comederos/ — comederos
- /tienda/ — perchas, accesorios

**Problema:** están en páginas con MUV poca tracción (jaulas: 20 imp, nidos: 2 imp, comederos: 14 imp). Las páginas con MILES de impresiones NO tienen ningún enlace de afiliado.

---

## Estrategia: 3 frentes

### Frente A — Poner afiliados en páginas que YA tienen tráfico
Las fichas de aves con +1,000 impresiones pueden llevar enlaces contextuales a:
- Prismáticos para avistamiento (binoculares)
- Guías de aves
- Cámaras para fotografía de aves
- Ropa de trekking/birdwatching

### Frente B — Expandir las páginas de producto que ya existen
/jaulas/, /nidos/, /comederos/ tienen intención de compra pero casi cero tráfico. Hay que:
1. Optimizarles título/meta para que aparezcan en Google
2. Agregar más productos relacionados
3. Crear contenido nuevo específico para compra

### Frente C — Crear nuevo contenido afiliado
Artículos tipo "mejores productos para..." orientados a keywords de compra.

## Reglas de afiliados (para el Copywriter/Técnico)
1. Los enlaces de afiliado deben ser CONTEXTUALES — no ponerlos porque sí
2. Usar texto de anclaje natural: "Si quieres observar águilas, te recomiendo estos prismáticos"
3. NO engañar al usuario (Google penaliza)
4. Usar enlace directo Amazon.es o acortador (amzn.to)
5. Añadir disclaimer: "Como afiliado de Amazon, gano por compras calificadas"
6. Priorizar productos con buena reputación (review >4 estrellas)
