# Asignacion Individual - Disenador UI Web
## Tareas: T-025 y T-026

### T-026 - Portada
Diseñá el primer pantallazo de la home para convertir mejor en mobile y desktop. El CTA principal debe quedar visible sin scroll.

### T-025 - Fichas foco
Rediseñá el hero de las fichas foco para que precio, ubicación, prueba social y CTA queden arriba del primer scroll.

### Entregable esperado
- Layout mobile-first.
- Jerarquía visual clara.
- CTA visible y dominante.

### Criterio de cierre
- Se entiende qué hacer al entrar.
- El diseño empuja a conversión.
