# Cobertura Real del Sitio - T-037
## Sesion: 2026-05-22

## Objetivo
Cruzar el research de keywords con la cobertura real de `avesnativachilenas.cl` y marcar en arquitectura si ya existe post o pagina para cada termino.

## Regla
- Si existe contenido, se registra URL exacta.
- Si no existe, queda como gap.
- Si existe de forma parcial, se marca como `SI/Parcial`.
