## Nuevos criterios SEO por ficha
| Elemento | Formato obligatorio |
|---|---|
| URL | /[ciudad]/[nombre-motel]/ |
| Title | `Motel [Nombre] en [Ciudad]` (max 65 caracteres) |
| Meta description | 145-160 caracteres, con precio y servicio diferencial |
| H1 | `Motel [Nombre] en [Ciudad]` |
| H2 | Descripcion, Datos de ubicacion y contacto, Precios y tarifas, Servicios y amenidades, Opiniones reales y mi opinion, Preguntas frecuentes |
| JSON-LD | @graph con WebPage, BreadcrumbList, Motel |
| Breadcrumbs | Chile > Ciudad > Motel |

## Auditoria SEO actualizada
| Aspecto | Estado | Accion |
|---|---|---|
| Estructura URL | Desactualizada | Migrar a /[ciudad]/[nombre-motel]/ |
| Title tags | Genericos | Cambiar a "Motel [Nombre] en [Ciudad]" |
| Meta descriptions | Faltan en 40% | Agregar con precio y diferencial |
| Datos estructurados | No hay | Implementar JSON-LD Motel + BreadcrumbList |
| Breadcrumbs | No existen | Agregar schema BreadcrumbList |
| Enlaces internos | Buenos | Mejorar desde hubs de ciudad a fichas individuales |
| NAP (nombre, direccion, telefono) | Inconsistente | Verificar contra fuente oficial cada ficha |
