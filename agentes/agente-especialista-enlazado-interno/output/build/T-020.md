# Build Enlazado Interno - T-020
## URL
`infomoteles.cl`

## Estado
Pendiente de aplicar cambios reales sobre URLs validas, con prioridad en `/para-moteles/`.

## Evidencia
- `homepage` concentra autoridad y debe empujar a la pagina comercial.
- `/para-moteles/` es la URL de conversion y no puede quedar aislada.
- Las fichas de ciudad deben actuar como hubs y no como paginas sueltas.

## Accion
1. Enlazar `homepage -> /para-moteles/`.
2. Enlazar `/moteles-en-santiago/ -> /para-moteles/`.
3. Enlazar `/moteles-en-valparaiso/ -> /para-moteles/`.
4. Convertir fichas huérfanas en hubs de ciudad.
5. Usar 301 solo con origen y destino exactos ya validados.

## Resultado esperado
- Mas autoridad hacia la URL comercial.
- Menos paginas huérfanas.
- Ruta clara desde SEO hacia contacto.

## Criterio de cierre
Cerrar solo cuando cada URL critica tenga destino definido, enlace contextual y no existan redirecciones ambiguas.
