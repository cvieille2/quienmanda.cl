## Arquitectura de enlazado para nuevas fichas

### Estructura de URLs
Cada ficha debe seguir: `/[ciudad]/[nombre-motel]/`

Ejemplos:
- `/santiago/motel-la-cascada/`
- `/santiago/motel-miraflores/`
- `/valparaiso/motel-encuentro/`

### Mapa de enlaces internos por ficha
```
Homepage
  └── Categoria: Moteles en [Ciudad] (hub de ciudad)
        └── Ficha: Motel [Nombre] en [Ciudad]
              ├── Breadcrumbs: Chile > [Ciudad] > Motel [Nombre]
              ├── Relacionados: otras fichas en misma ciudad
              └── Desde homepage si es Premium
```

### Prioridad de enlazado
| Prioridad | Accion | Donde |
|---|---|---|
| Alta | Enlace desde hub de ciudad | Pagina /[ciudad]/ con shortcode [fichas_motel] |
| Alta | Breadcrumbs con schema | Template de ficha |
| Alta | Enlaces cruzados contextuales | Dentro del contenido principal |
| Media | Enlace desde homepage para fichas Premium | Homepage, seccion destacados |
| Media | Enlaces desde fichas de ciudades vecinas | Ej: ficha en Santiago enlaza a Vina del Mar |
| Baja | Enlaces desde articulos de blog relacionados | Articulos que mencionan el motel o la ciudad |

### Checklist por ficha publicada
- [ ] Tiene enlace desde el hub de su ciudad
- [ ] Breadcrumbs Chile > Ciudad > Motel visibles y con schema
- [ ] Al menos 3 fichas relacionadas enlazadas de forma contextual en el contenido
- [ ] Anchor text descriptivo (no "ver mas", "aqui", "click")
- [ ] No es pagina huerfana (tiene al menos 1 enlace interno entrante)
- [ ] Si es Premium: enlace desde homepage
