## Notas tecnicas de implementacion

1. **Jerarquia WordPress**: Usar `parent` para que las URLs hereden correctamente. Ej: `/jaulas/` (ID 6492) es padre de `/jaulas/para-loros/`, y `/jaulas/para-loros/` es padre de `/jaulas/para-guacamayos/`.
2. **Anchor texts**: No repetir el mismo anchor text en mas de 3 enlaces diferentes para evitar sobreoptimizacion.
3. **Enlaces de afiliado**: Cada post debe incluir 2+ enlaces de afiliado contextuales + disclaimer.
4. **Breadcrumbs**: Configurar Yoast para que muestre la jerarquia de padres correcta.
5. **Cobayas/Hamster**: Excluidos del plan por decision editorial (riesgo de dilucion tematica).
6. **Gallos de pelea**: Incluidos en plan pero con tono neutro/tecnico. Decidir ubicacion final.
