# Mejorar Prompt

Objetivo:
- Convertir prompts vagos en instrucciones claras, ejecutables y medibles.

Checklist:
- Detectar objetivo principal.
- Eliminar ambiguedad, ruido y repeticiones.
- Añadir contexto minimo util.
- Definir formato de salida.
- Pedir solo las preguntas imprescindibles.

Reglas:
- No cambiar la intencion del usuario.
- No alargar por estetica.
- Preferir claridad sobre creatividad.
- Si falta informacion critica, explicitarla.

Salida recomendada:
1. Prompt mejorado
2. Version corta
3. Supuestos
4. Preguntas criticas, solo si hacen falta
